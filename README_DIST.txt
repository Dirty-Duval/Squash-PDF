Squash PDF Compressor
===============================================================

Thank you for installing Squash PDF Compressor!

WHAT IS SQUASH?
Squash is a simple PDF compression tool for Windows. It uses the
bundled Ghostscript engine to shrink PDF files while keeping them
readable. Everything happens on your computer; nothing is uploaded.

FEATURES:
- Drag and drop PDF files or whole folders onto the window
- 3 quality presets (Small, Medium, High Quality) plus custom presets
- Live progress with speed and time remaining, and a Cancel button
- Results view with before/after comparison for every file
- Choose where compressed files go and how they are named
  (originals are never overwritten)
- Compression history with statistics and trends
- Dark / light / system theme
- Optional automatic update check via GitHub Releases

SYSTEM REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit)
- 200 MB free disk space
- No additional software required (Ghostscript is included)

QUICK START:
1. Run Squash
2. Drag PDF files into the window (or click the drop zone to browse)
3. Pick a quality preset
4. Click "Compress Now"
5. Click "Open Output Folder" in the results window

TIPS:
- The line under the presets shows where files will be saved.
  Change it in Settings > Output.
- If a file comes out larger, it was already well compressed;
  keep the original.
- Password-protected PDFs cannot be compressed. Remove the password first.
- Very large scanned PDFs may need a higher time limit (Settings > Compression).

FILE LOCATIONS:
- Settings:        %APPDATA%\Squash\settings.json
- History:         %APPDATA%\Squash\history\
- Custom presets:  %APPDATA%\Squash\presets\
- Logs:            %APPDATA%\Squash\logs\  (Settings > Open Log Folder)
